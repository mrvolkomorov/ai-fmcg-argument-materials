## Правило отбора ссылок

Каждая ссылка проходит проверку полезности: она должна закрывать конкретный шаг домашнего задания или разбор симуляции. Поэтому в блоке «Где брать факты» — только первоисточники (государственная статистика, регулятор, биржа, грузовой оператор), а не пересказы в СМИ и не маркетинговые обзоры. Все внешние ссылки открыты и проверены.
